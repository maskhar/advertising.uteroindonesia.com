# Product Requirements Document (PRD)
# Utero Advertising Website

## 1. Overview
Website untuk Utero Advertising, perusahaan jasa reklame outdoor & indoor di Malang, dibangun menggunakan Vite untuk performa optimal dan modern development experience.

## 2. Business Objectives
- Menampilkan portofolio dan layanan Utero Advertising secara profesional
- Meningkatkan lead generation melalui WhatsApp integration
- Membangun kredibilitas dengan menampilkan klien-klien besar
- Memberikan informasi lengkap tentang proses kerja dan legalitas

## 3. Target Audience
- Pemilik usaha yang membutuhkan jasa reklame
- Marketing manager perusahaan
- Developer properti
- Event organizer
- Lokasi: Malang, Surabaya, Mojokerto, Madiun

## 4. Core Features

### 4.1 Hero Section
- Tagline utama yang impactful
- CTA langsung ke WhatsApp
- Visual yang menarik perhatian

### 4.2 Layanan
- Billboard & Videotron
- Neon Box & Signage
- Papan Nama Toko
- Baliho, Spanduk, Umbul-umbul
- Percetakan Digital
- Interior & Eksterior
- Event Support

### 4.3 Portofolio
- Gallery dengan lightbox
- Dokumentasi project sebelumnya
- Filter berdasarkan kategori (opsional)

### 4.4 Proses Kerja
- 4 tahap: Konsultasi → Desain → Produksi → Instalasi
- Visual timeline yang jelas

### 4.5 Legal & Dokumentasi
- Perizinan reklame
- Pajak reklame
- Laporan real-time
- Dokumentasi lengkap

### 4.6 Social Proof
- Marquee klien-klien besar
- Testimoni (jika ada)

### 4.7 Footer
- Informasi kontak lengkap
- Alamat kantor
- Link social media
- WhatsApp, email, telepon

## 5. Technical Requirements
- **Framework**: Vite + Vanilla JS (atau React/Vue jika diperlukan)
- **Responsive**: Mobile-first approach
- **Performance**: Lazy loading images, optimized assets
- **SEO**: Meta tags lengkap, semantic HTML
- **Analytics**: Google Analytics ready (opsional)

## 6. Design Requirements
- Font: Anton (headings), Inter (body)
- Color scheme: Red (#E31E24), neutral tones
- Industrial/blueprint aesthetic dengan bracket corners
- Smooth animations dan transitions
- Card-based layout

## 7. Success Metrics
- Page load time < 3 detik
- Mobile responsive 100%
- WhatsApp click-through rate
- Bounce rate < 50%

## 8. Future Enhancements
- CMS untuk update portofolio
- Multi-language support
- Blog untuk SEO
- Online quotation form
- Live chat integration
